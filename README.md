## 🔥 Ключевые особенности

**WIC** - это мощный нативный менеджер окон для macOS, разработанный для максимальной производительности и удобства. Приложение предоставляет полный контроль над позиционированием окон с помощью горячих клавиш, автоматических раскладок и интеллектуального управления окнами.

### 🎯 Основные возможности

- **🖱️ Умное позиционирование окон**: Быстрое размещение окон в половину, треть, четверть экрана
- **🤖 Автоматические раскладки**: 6 типов автолайаута для оптимального распределения окон
- **⌨️ Глобальные горячие клавиши**: 17+ настраиваемых комбинаций клавиш
- **🖥️ Мультимониторная поддержка**: Полная поддержка нескольких дисплеев
- **📺 Распознавание LG OLED 42"**: Автоматическая идентификация и оптимизация для LG OLED дисплеев
- **🧲 Автоматическое приклеивание**: Интеллектуальное распознавание краев экрана
- **📊 Профилирование производительности**: Детальное логирование всех операций
- **🎨 Темная и светлая темы**: Адаптивный интерфейс под системную тему
- **💾 Сохранение настроек**: Персистентные настройки и раскладки

### 🤖 Система автолайаута

WIC предлагает 6 уникальных алгоритмов автоматического позиционирования окон:

| Раскладка | Описание | Иконка |
|-----------|----------|--------|
| **Сетка** | Равномерное распределение окон в сетке | `square.grid.2x2` |
| **Горизонтальная** | Окна расположены горизонтально | `rectangle.split.3x1` |
| **Вертикальная** | Окна расположены вертикально | `rectangle.split.1x3` |
| **Каскад** | Каскадное смещение окон | `square.stack.3d.up` |
| **Фибоначчи** | Распределение по золотому сечению | `circle.grid.3x3` |
| **Фокус** | Главное окно + боковая панель | `rectangle.split.2x1` |

### ⌨️ Горячие клавиши

#### Половины экрана
- `⌘ ⌥ ←` - Левая половина экрана
- `⌘ ⌥ →` - Правая половина экрана
- `⌘ ⌥ ↑` - Верхняя половина экрана
- `⌘ ⌥ ↓` - Нижняя половина экрана

#### Трети экрана
- `⌘ ⌥ D` - Левая треть
- `⌘ ⌥ F` - Центральная треть
- `⌘ ⌥ G` - Правая треть
- `⌘ ⌥ E` - Левые две трети
- `⌘ ⌥ T` - Правые две трети

#### Четверти экрана
- `⌃ ⌘ ↑` - Левая верхняя четверть
- `⌃ ⌥ ⌘ U` - Правая верхняя четверть
- `⌃ ⌥ ⌘ J` - Левая нижняя четверть
- `⌃ ⌥ ⌘ K` - Правая нижняя четверть

#### Специальные функции
- `⌘ ⌥ C` - Центрировать окно
- `⌘ ⌥ ↩` - Максимизировать окно
- `⌘ ⌥ L` - Применить автолайаут (сетка)
- `⌘ ⌥ ⇧ L` - Применить автолайаут (фокус)

### 📊 Система логирования

WIC включает продвинутую систему логирования для профилирования производительности:

- **📈 Профилирование**: Автоматическое отслеживание производительности
- **🔍 Уровни логирования**: Debug, Info, Warning, Error, Performance
